# eng-team v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Evolve the review-only eng-team Claude Code plugin (v1.0.0) into v2.0.0. v2 is a full-lifecycle engineering team (discover → research → architect → build → test → document → review) with a challenger protocol, tiered knowledge packs, gated/autonomous modes, project state, docs-as-code output and a tested plugin.

**Architecture:** One orchestrator skill (`skills/eng-team/SKILL.md`) drives phase files (`phases/*.md`). It dispatches role agents (`agents/eng-*.md`) whose write rights are enforced by their `tools:` frontmatter, and persists progress in the *target* project's `.eng-team/` folder. Knowledge comes from packs (stack / compliance / practice) resolved project → federation → plugin by `applies_when` rules over profile fields. A stdlib-only Python validator enforces the structure; `claude plugin eval` cases with fixtures check behaviour.

**Tech Stack:** Claude Code plugin format (Markdown + YAML frontmatter), Python 3 stdlib (validator), Bash, GitHub Actions, `claude plugin eval` (CLI 2.1.300).

**Spec:** `/Users/g/Documents/GitHub/engineering-team/docs/superpowers/specs/2026-10-15-eng-team-v2-design.md`. Read it before any task; section refs below (§n) point into it.

## Context

v1 (`/Users/g/Documents/GitHub/engineering-team/eng-team-plugin/`) is an eng-lead orchestrator with 9 read-only reviewer agents, 5 stack packs, 6 compliance packs, and modes plan/review/gate. The user (George Yakoub) runs an in-house federation of decentralized developer groups and also works solo/freelance. They want one plugin that researches, challenges, architects, builds, tests and documents for any project, platform or jurisdiction, and stays regulation-aware. ## Findings & insights from exploration (why this shape)

- **Duplicate tree.** `/Users/g/Documents/GitHub/engineering-team/eng-team/` is a byte-identical copy of `eng-team-plugin/skills/eng-team/` (verified with `diff -rq`). Task 1 deletes it so there is one source of truth.
- **Rights live in `tools:` frontmatter.** v1 agents are 16-line shells: frontmatter `tools: Read, Grep, Glob` plus 5 numbered rules telling them to read their role file. Write rights are enforced by `tools:`, not prompts. That is why the validator checks tool lists (§3.4).
- **Researcher and architect have no Write tool**, by spec §3.1. They *return* pack, note and ADR content, and the **orchestrator (main thread, all tools) writes it** into `.eng-team/` or `docs/adr/`. The tech-writer later polishes `docs/`. This keeps §3.4 intact; do not add Write to those agents.
- **context7 tool names differ by install method.** As a standalone MCP they are `mcp__context7__resolve-library-id` / `mcp__context7__query-docs`; as the official plugin they are `mcp__plugin_context7_context7__resolve-library-id` / `mcp__plugin_context7_context7__query-docs`. The researcher lists all four, and its role file falls back to WebFetch on official docs when neither is present.
- **Eval format** (verified with `claude plugin eval init --bare`):
  - A case is `<evals dir>/<case>/prompt.md`, with frontmatter `max_turns` and `allowed_tools`, plus `graders/*.md` with frontmatter `type: llm` and `weight: N`.
  - The manifest key `experimental.evals` sets the eval dir.
  - The CLI supports `scaffold_script` (needs the `--scaffold` flag) and `--runs`, `--threshold`, `--trust-plugin`, `--no-publish`.
  - The exact `case.yaml` key for a scaffold script is **not** printed by `--help`. Task 11 Step 1 resolves it.
- **v1 packs have no frontmatter.** v1 selection tables live in `shared/project-profile.md` ("Compliance profile selection"). Those tables are the source for each pack's `applies_when` in Task 3.
- **`yq` is not installed; `python3` and `jq` are.** The validator therefore uses Python stdlib only, with a minimal frontmatter parser (no PyYAML dependency).
- **Commands namespace.** Plugin commands in `commands/eng-discover.md` are invocable as `/eng-discover`, or as `/eng-team:eng-discover` if names clash. The README documents both.

## Global Constraints

- Plugin root: `/Users/g/Documents/GitHub/engineering-team/eng-team-plugin/`. Skill root: `<plugin>/skills/eng-team/`. All relative paths below are from the repo root `/Users/g/Documents/GitHub/engineering-team/` unless stated.
- Version `2.0.0` in `eng-team-plugin/.claude-plugin/plugin.json`.
- **Commit messages: no `Co-Authored-By` and no "Generated with Claude Code" lines** (user's global rule; overrides any harness default).
- **GitHub repo `Yakoub-ai/engineering-team` stays PRIVATE.** Never change visibility.
- Write rights (§3.4):
  - `eng-builder` and `eng-tester` have `Read, Grep, Glob, Write, Edit, Bash`.
  - `eng-tech-writer` has `Read, Grep, Glob, Write, Edit` (no Bash).
  - `eng-researcher` has `Read, Grep, Glob, WebFetch, WebSearch` + the 4 context7 tools.
  - All other agents have exactly `Read, Grep, Glob`.
- Pack frontmatter keys (§6.1): `id, kind, status, tier, sources, reviewed_by, review_by, applies_when`.
  - `kind` ∈ stack|compliance|practice; `status` ∈ reviewed|unreviewed|deprecated; `tier` ∈ plugin|federation|project.
  - Pack body ≤ 60 lines.
  - Curated packs: `tier: plugin`, `status: reviewed`, `reviewed_by: George Yakoub`, `review_by: 2027-04-15`.
- `applies_when` grammar: the literal `always`, or an expression over `profile.<field>` with operators `==`, `!=`, `contains`, `AND`, `OR`, `NOT`, parentheses and double-quoted strings. Field names must exist in `templates/profile.md`.
- Unreviewed-pack findings are capped at High unless the check quotes a regulation article verbatim with citation (§6.3).
- Hard stops in every autonomy mode (§4):
  - a Critical finding
  - a test suite not fixed within 2 attempts
  - destructive operations (data migrations, deletions, production deploys)
  - actions outside the repository
- A loop runs at most 3 iterations, then escalates.
- Doc limits (§7):
  - brief ≤ 1 page (~60 lines); architecture ≤ ~3 pages (~180 lines); ADR ≤ 1 page (~60 lines).
  - Every doc starts with `Audience:` and `Last verified against: <commit>`.
- No `TODO`, `TBD` or `FIXME` in shipped plugin files (validator enforces).
- Use absolute dates (YYYY-MM-DD) everywhere.

## Review Focus

Behaviours a real user will hit that no happy-path test exercises. Each has an eval case in Task 11 and explicit handling in the owning task.

1. **A phase command run in a project with no `.eng-team/`** (e.g. `/eng-build` first). It must refuse, explain, and offer `/eng-init`, not improvise a profile. Owner: Task 7 (SKILL.md "Preconditions"); eval `d-build-without-init`.
2. **A profile stack or jurisdiction with no matching pack** (e.g. `stacks: [sap-btp]`, `jurisdictions: [uk]`). It must take the research-on-demand path, write an `unreviewed` project pack and say so; never skip silently. Owner: Task 6 (researcher) + Task 7 (resolution); eval `e-unknown-stack-research`.
3. **`profile.standards` points to a path or URL that doesn't exist.** It must warn once, log the warning in `state.md`, and continue with plugin-tier packs, without crashing or pretending the standards loaded. Owner: Task 7; eval `f-missing-standards`.
4. **`/eng-document` re-run when `docs/` already has human edits.** It must update in place (diff against code) and keep human-written paragraphs, never regenerate. Owner: Task 6 (tech-writer) + Task 7 (`phases/document.md`); eval `g-docs-preserve`.
5. **`state.md` hand-edited or inconsistent** (e.g. `current_phase: build` but the architect gate isn't `passed`). It must report the inconsistency, reconstruct status from artifacts, and ask (gated) or take the earliest unpassed gate (autonomous), never silently overwrite. Owner: Task 7 (SKILL.md "State integrity"); eval `h-state-inconsistent`.

#!/usr/bin/env bash
# Builds a minimal valid plugin, asserts the validator passes, then applies one
# mutation per check and asserts the validator fails naming that check.
set -u
HERE="$(cd "$(dirname "$0")" && pwd)"
VALIDATE="$HERE/../../scripts/validate.sh"
fails=0

make_good() {
  local d="$1"
  mkdir -p "$d/.claude-plugin" "$d/agents" "$d/skills/eng-team/phases" \
           "$d/skills/eng-team/templates" "$d/skills/eng-team/stacks"
  echo '{"name":"eng-team","version":"2.0.0"}' > "$d/.claude-plugin/plugin.json"
  cat > "$d/agents/eng-builder.md" <<'EOF'
---
name: eng-builder
description: "builder"
tools: Read, Grep, Glob, Write, Edit, Bash
---
body
EOF
  cat > "$d/agents/eng-architect.md" <<'EOF'
---
name: eng-architect
description: "architect"
tools: Read, Grep, Glob
---
body
EOF
  cat > "$d/skills/eng-team/SKILL.md" <<'EOF'
---
name: eng-team
description: orchestrator
---
Run `phases/build.md`.
EOF
  cat > "$d/skills/eng-team/phases/build.md" <<'EOF'
# Phase: build
## Purpose
x
## Inputs
x
## Steps
x
## Exit criteria
x
## Autonomous mode
x
EOF
  cat > "$d/skills/eng-team/templates/profile.md" <<'EOF'
# Profile
```yaml
name:
stacks: []
regulated:
  financial_entity: no
```
EOF
  cat > "$d/skills/eng-team/stacks/azure.md" <<'EOF'
---
id: azure
kind: stack
status: reviewed
tier: plugin
sources:
  - title: Azure Well-Architected
    url: https://learn.microsoft.com/azure/well-architected/
    accessed: 2026-10-15
reviewed_by: George Yakoub
review_by: 2027-04-15
applies_when: profile.stacks contains "azure" AND profile.regulated.financial_entity != "yes"
---
# Stack pack: Azure
- check
EOF
}

expect_pass() {
  local d; d="$(mktemp -d)"; make_good "$d"
  if "$VALIDATE" "$d" >/dev/null; then echo "ok   good plugin passes"
  else echo "FAIL good plugin should pass:"; "$VALIDATE" "$d"; fails=$((fails+1)); fi
}

expect_fail() {   # $1 = check name, $2 = mutation (bash run inside plugin dir)
  local d; d="$(mktemp -d)"; make_good "$d"
  (cd "$d" && eval "$2")
  local out; out="$("$VALIDATE" "$d" 2>&1)"; local rc=$?
  if [ $rc -ne 0 ] && grep -q "^$1:" <<<"$out"; then echo "ok   $1 detected"
  else echo "FAIL expected '$1' error, got rc=$rc:"; echo "$out"; fails=$((fails+1)); fi
}

expect_pass
expect_fail rights       "sed -i.bak 's/tools: Read, Grep, Glob$/tools: Read, Grep, Glob, Write/' agents/eng-architect.md"
expect_fail refs         "echo 'See \`phases/missing.md\`.' >> skills/eng-team/SKILL.md"
expect_fail applies      "sed -i.bak 's/profile.stacks contains/profile.cloud contains/' skills/eng-team/stacks/azure.md"
expect_fail packs        "sed -i.bak '/^review_by:/d' skills/eng-team/stacks/azure.md"
expect_fail headings     "sed -i.bak '/^## Exit criteria/d' skills/eng-team/phases/build.md"
expect_fail placeholders "echo 'TODO finish' >> skills/eng-team/SKILL.md"
expect_fail frontmatter  "printf 'no frontmatter\n' > agents/eng-broken.md"

[ $fails -eq 0 ] && echo "ALL VALIDATOR TESTS PASSED" || { echo "$fails validator test(s) failed"; exit 1; }
```

Note: the mutations leave `.bak` files (from `sed -i.bak`, needed for macOS/GNU portability). The validator must ignore any file not ending in `.md` or `.json`.

Create `eng-team-plugin/scripts/validate.py`:

```python
#!/usr/bin/env python3
"""Structural validator for the eng-team plugin (stdlib only).

Usage: validate.py [plugin_root] [--only check1,check2]
Checks: frontmatter, refs, packs, applies, rights, headings, placeholders.
Prints '<check>: <path>: <message>' per error; exit 1 if any.
"""
import pathlib
import re
import sys

CHECKS = ["frontmatter", "refs", "packs", "applies", "rights", "headings", "placeholders"]

READ_ONLY = {"Read", "Grep", "Glob"}
CONTEXT7 = {
    "mcp__context7__resolve-library-id", "mcp__context7__query-docs",
    "mcp__plugin_context7_context7__resolve-library-id",
    "mcp__plugin_context7_context7__query-docs",
}
ALLOWED_TOOLS = {
    "eng-builder": READ_ONLY | {"Write", "Edit", "Bash"},
    "eng-tester": READ_ONLY | {"Write", "Edit", "Bash"},
    "eng-tech-writer": READ_ONLY | {"Write", "Edit"},
    "eng-researcher": READ_ONLY | {"WebFetch", "WebSearch"} | CONTEXT7,
}
REQUIRED_TOOLS = {
    "eng-builder": {"Write", "Edit", "Bash"},
    "eng-tester": {"Write", "Edit", "Bash"},
    "eng-tech-writer": {"Write", "Edit"},
}
PACK_DIRS = {"stacks": "stack", "compliance": "compliance", "practices": "practice"}
PACK_KEYS = ["id", "kind", "status", "tier", "sources", "reviewed_by", "review_by", "applies_when"]
PACK_BODY_MAX = 60
HEADINGS = {
    "phases": ["## Purpose", "## Inputs", "## Steps", "## Exit criteria", "## Autonomous mode"],
    "challenger": ["## Purpose", "## Protocol", "## Output"],
}
NEW_ROLES = {"researcher", "architect", "builder", "tester", "tech-writer"}
ROLE_HEADINGS = ["**Mission:**", "**Owns:**", "## Method", "## Output"]
REF_RE = re.compile(r"`((?:roles|phases|challenger|stacks|compliance|practices|templates|shared)/[\w.-]+\.md)`")
FIELD_RE = re.compile(r"profile\.([A-Za-z_][\w.]*)")
PLACEHOLDER_RE = re.compile(r"\b(TODO|TBD|FIXME)\b")


def split_frontmatter(text):
    """Return (dict, body) or (None, text). Top-level keys only; continuation lines appended."""
    if not text.startswith("---\n"):
        return None, text
    end = text.find("\n---\n", 4)
    if end == -1:
        return None, text
    fm, key = {}, None
    for line in text[4:end].splitlines():
        if not line.strip() or line.lstrip().startswith("#"):
            continue
        m = re.match(r"^([A-Za-z_][\w-]*):\s*(.*)$", line)
        if m:
            key = m.group(1)
            fm[key] = m.group(2).strip()
        elif key:
            fm[key] = (fm[key] + "\n" + line).strip()
    return fm, text[end + 5:]


def profile_fields(skill):
    """Field names from the yaml block in templates/profile.md, nested as parent.child."""
    path = skill / "templates" / "profile.md"
    if not path.exists():
        return None
    block = re.search(r"```yaml\n(.*?)```", path.read_text(), re.S)
    fields, parent = set(), None
    for line in (block.group(1) if block else "").splitlines():
        top = re.match(r"^([A-Za-z_]\w*):", line)
        sub = re.match(r"^  ([A-Za-z_]\w*):", line)
        if top:
            parent = top.group(1)
            fields.add(parent)
        elif sub and parent:
            fields.add(f"{parent}.{sub.group(1)}")
    return fields


def md_files(root):
    skip = {"tests", "evals", "results"}
    return [p for p in root.rglob("*.md") if not (set(p.relative_to(root).parts) & skip)]


def main(argv):
    args = [a for a in argv if not a.startswith("--only")]
    only = next((a.split("=", 1)[1] if "=" in a else argv[argv.index(a) + 1]
                 for a in argv if a.startswith("--only")), None)
    if only and only in args:
        args.remove(only)
    root = pathlib.Path(args[0] if args else pathlib.Path(__file__).resolve().parent.parent)
    run = set(only.split(",")) if only else set(CHECKS)
    skill = root / "skills" / "eng-team"
    errors = []

    def err(check, path, msg):
        if check in run:
            rel = path.relative_to(root) if path.is_absolute() and root in path.parents else path
            errors.append(f"{check}: {rel}: {msg}")

    # frontmatter + rights
    for kind, req in (("agents", ["name", "description", "tools"]), ("commands", ["description"])):
        for p in sorted((root / kind).glob("*.md")):
            fm, _ = split_frontmatter(p.read_text())
            if fm is None:
                err("frontmatter", p, "missing or unterminated frontmatter")
                continue
            for k in req:
                if not fm.get(k):
                    err("frontmatter", p, f"missing key '{k}'")
            if kind == "agents" and fm.get("tools"):
                tools = {t.strip() for t in fm["tools"].split(",") if t.strip()}
                name = fm.get("name", p.stem)
                allowed = ALLOWED_TOOLS.get(name, READ_ONLY)
                extra = tools - allowed
                if extra:
                    err("rights", p, f"{name} must not have {sorted(extra)}")
                missing = REQUIRED_TOOLS.get(name, set()) - tools
                if missing:
                    err("rights", p, f"{name} needs {sorted(missing)}")
    skill_md = skill / "SKILL.md"
    if skill_md.exists():
        fm, _ = split_frontmatter(skill_md.read_text())
        if fm is None or not fm.get("name") or not fm.get("description"):
            err("frontmatter", skill_md, "SKILL.md needs name and description")

    # refs
    for p in md_files(root):
        for ref in REF_RE.findall(p.read_text()):
            if not (skill / ref).exists():
                err("refs", p, f"references missing file {ref}")

    # packs + applies
    fields = profile_fields(skill)
    for d, kind in PACK_DIRS.items():
        for p in sorted((skill / d).glob("*.md")):
            fm, body = split_frontmatter(p.read_text())
            if fm is None:
                err("packs", p, "pack has no frontmatter")
                continue
            for k in PACK_KEYS:
                if k not in fm or (k != "reviewed_by" and not fm[k]):
                    err("packs", p, f"missing key '{k}'")
            if fm.get("kind") and fm["kind"] != kind:
                err("packs", p, f"kind '{fm['kind']}' should be '{kind}'")
            if fm.get("status") and fm["status"] not in {"reviewed", "unreviewed", "deprecated"}:
                err("packs", p, f"bad status '{fm['status']}'")
            if fm.get("tier") and fm["tier"] != "plugin":
                err("packs", p, "curated packs must be tier: plugin")
            if fm.get("sources") and "url:" not in fm["sources"]:
                err("packs", p, "sources need at least one url")
            if fm.get("review_by") and not re.fullmatch(r"\d{4}-\d{2}-\d{2}", fm["review_by"]):
                err("packs", p, "review_by must be YYYY-MM-DD")
            if len(body.strip().splitlines()) > PACK_BODY_MAX:
                err("packs", p, f"body exceeds {PACK_BODY_MAX} lines")
            aw = fm.get("applies_when", "")
            if aw and aw != "always":
                if fields is None:
                    err("applies", p, "templates/profile.md missing; cannot check fields")
                    continue
                used = FIELD_RE.findall(aw)
                if not used:
                    err("applies", p, "applies_when must be 'always' or reference profile.<field>")
                for f in used:
                    if f not in fields:
                        err("applies", p, f"unknown profile field '{f}'")

    # headings
    for d, heads in HEADINGS.items():
        for p in sorted((skill / d).glob("*.md")):
            text = p.read_text()
            for h in heads:
                if not re.search(rf"^{re.escape(h)}\s*$", text, re.M):
                    err("headings", p, f"missing heading '{h}'")
    for r in NEW_ROLES:
        p = skill / "roles" / f"{r}.md"
        if p.exists():
            text = p.read_text()
            for h in ROLE_HEADINGS:
                if h not in text:
                    err("headings", p, f"missing '{h}'")

    # placeholders
    for p in md_files(root):
        if p.name == "CHANGELOG.md":
            continue
        for n, line in enumerate(p.read_text().splitlines(), 1):
            if PLACEHOLDER_RE.search(line):
                err("placeholders", p, f"line {n}: placeholder text")

    for e in errors:
        print(e)
    return 1 if errors else 0


if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))
```
